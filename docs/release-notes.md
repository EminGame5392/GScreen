GScreen splits one ultrawide monitor into 2–3 real Windows monitors and merges it back for games with Ctrl+Alt+G.

Requirements: Windows 11, the [Virtual Display Driver](https://github.com/VirtualDrivers/Virtual-Display-Driver)
(`winget install --id=VirtualDrivers.Virtual-Display-Driver -e`).

Unzip anywhere and run `GScreen.App.exe`. To uninstall, see the README.
